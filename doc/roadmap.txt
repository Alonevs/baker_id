RISC-V: desarrollo y consola realEn PC (ahora)Toolchain: riscv64-unknown-elf o la variante que elijas (32/64 según chip).Emulador: QEMU, o emulador propio en Rust (forge-riscv-emu).El runtime (forge-runtime) se compila para RISC-V y enlaza con el juego.En consola (futuro)Mismo ISA RISC-V que en emulación.Firmware en Rust: boot, lector de cartucho, framebuffer, audio, inputs.Cartucho = ROM con header (magic, versión, checksum, tamaño) + payload del juego.┌─────────────────────────────────┐│ Header (id juego, versión, CRC)   │├─────────────────────────────────┤│ Código (runtime + lógica mínima)│├─────────────────────────────────┤│ Assets (sprites, mapas, audio)  │├─────────────────────────────────┤│ Datos (eventos, diálogos, flags)│└─────────────────────────────────┘        ≤ 600 MB totalRegla de oro: si corre en el emulador, debe correr en la consola (misma ABI, mismos límites).8. Resumen en una fraseUn SDK/IDE en Rust para juegos 2.5D (isométrico, plataforma, run-and-gun), con Event Forge para cinemáticas/eventos, compilados para RISC-V, probados en emulador y publicados en cartuchos de hasta 600 MB y 10 000 sprites, para una consola portátil real que construirás después.
